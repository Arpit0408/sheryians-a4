# Deepstyle Fashion Landing Page

This is a clean frontend landing page built to practice complex grid alignment using HTML and CSS. The design focuses on arranging multiple product/model cards in a structural, symmetric grid layout.

## Live Project
Link: https://sheryians-a4.vercel.app/

## How the Layout Works
The layout is handled using CSS Grid with a 5-column and 2-row setup. 

- Center Element: The main yellow card uses grid-row span 2 to cover the full height from top to bottom.
- Flanking Cards: The rest of the images drop naturally into their assigned row and column tracks on both sides of the center card.
- Text & Floating Elements: The text wrapper and rotating circular badge are aligned using precise CSS placement so they do not disturb the main grid items.

## Technologies Used
- HTML5 for semantic page layout
- CSS3 for grid tracks, styling, and text animations
- Google Material Icons for UI buttons

## Setup Instructions
1. Download or clone this repository.
2. Open index.html inside any modern web browser.
3. Make sure the assets folder contains the correct images so paths load properly.
